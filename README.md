# Игра-мозаика

Адаптивная браузерная мозаика: картинка делится на квадратные фрагменты, которые нужно собрать обратно. Чистый фронтенд-SPA без базы данных и бэкенда.

**Демо:** [https://mikhail-ilnitsky.github.io/Vibe_MosaicGame_JS-Vue_Cursor-Grok-4-6/](https://mikhail-ilnitsky.github.io/Vibe_MosaicGame_JS-Vue_Cursor-Grok-4-6/)

В GitHub: **Settings → Pages**, источник — ветка по умолчанию, папка `/docs`.

## Возможности

- Галерея из шести картинок с локализацией RU/EN (язык по `navigator.language`)
- Автоматический расчёт сеток сложности: по короткой стороне N = 5…11 квадратов, по длинной — целое число клеток с центрированной обрезкой остатка
- Два способа управления сразу: клик-клик и перетаскивание через Pointer Events
- Игровое поле вписывается в экран и не растягивается сверх исходного размера нарезки
- Счётчик ходов, просмотр обрезанного оригинала, жёлтая вспышка и сообщение о победе

## Стек

| Технология | Версия | Назначение |
| --- | --- | --- |
| JavaScript | ES2020, без сборщика | Логика сетки, ходов и управления |
| Vue | 3.5.42 (CDN, только Options API) | Экраны, состояние и шаблон |
| CSS | CSS3 | Вёрстка, адаптив и фрагменты через `background-*` |

## Происхождение проекта

Исходная версия сгенерирована в Cursor по техническому заданию [`prompts/INITIAL.md`](prompts/INITIAL.md). Подробный контекст для следующих сессий — [`.cursor/CONTEXT.md`](.cursor/CONTEXT.md).

## Структура

```
docs/
  index.html      точка входа SPA, относительные пути
  css/style.css   минималистичные стили и адаптив
  js/images.js    фиксированный массив картинок
  js/i18n.js      строки RU/EN и определение языка
  js/puzzle.js    сетка, нарезка CSS-фоном, перемешивание
  js/app.js       приложение Vue 3 (Options API)
```
