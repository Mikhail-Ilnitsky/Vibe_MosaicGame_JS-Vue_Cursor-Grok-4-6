# Mosaic Game — контекст проекта

Адаптивная браузерная игра-мозаика. Точка входа: `docs/index.html`. Деплой на GitHub Pages из папки `/docs` (относительные пути `./...`).

## Стек

- JavaScript без сборщика и компиляции
- Vue 3.5.42 с CDN, только Options API (`vue.global.prod.js`)
- CSS3
- Бэкенд и база не используются

## Ключевые решения

**Сетка.** Короткой стороне исходника всегда соответствует N клеток (5…11). Размер клетки: `floor(minSide / N)`. По длинной стороне число клеток — `floor(longSide / tileSize)`. Остаток пикселей обрезается и центрируется. Примеры для 1000×700: N=7 → 10×7 по 100; N=5 → 7×5 по 140; N=6 → 8×6 по 116.

**Отображение поля.** Доска вписывается в оставшуюся область через CSS container queries: `min(100cqi, usedW, 100cqb * cols/rows)`. Масштаб не больше 1:1 — картинку не растягивать.

**CSS-фрагменты.** Картинку не режем. Каждая плитка — `div` с `background-image`. Формула `background-size` / `background-position` из ТЗ обобщена на центрированную обрезку: без остатка она совпадает с `(cols * 100%)` и `x / (cols - 1) * 100%`. Свойства фона привязаны к исходным координатам плитки и не меняются при перемешивании.

**Управление.** Клик-клик (выделение и обмен) и Pointer Events (`pointerdown` / `pointermove` / `pointerup`). Порог драга — половина стороны плитки. Ход — обмен двух плиток. Перемешивание: N случайных парных обменов для N плиток.

**i18n.** Переключатель RU/EN в шапке справа. Старт: `navigator.language` содержит `ru` → RU, иначе EN. `<title>` всегда «Игра-мозаика».

**Победа.** Все плитки на своих местах → сообщение под полем, жёлтая вспышка 500 мс, затем сетка сменяется той же обрезанной картинкой (не полным файлом из галереи). «Начать новую игру» и «Выход» ведут в галерею.

**Деплой.** Файлы сайта в `docs/`. GitHub Pages: ветка по умолчанию, папка `/docs`.
